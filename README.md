# 鉱石おみくじ ⛏

群馬大学の学園祭にて、**地学部の「宝石おみくじ」ブース**で使用する Web アプリケーションの試作品です。

来場者がスマートフォンで画面をタップして高山を掘り、掘り当てた鉱石に応じた **運勢（おみくじ）** と、実物の宝石と引き換えできる **引換券** が表示されます。`index.html` 1 枚だけで動く、ビルド不要のシンプルな構成です。

> [!IMPORTANT]
> **DB との接続や設計については、改めて運用に合わせて設計する必要あり**（現状はプロトタイプ）。

## 遊び方

1. くじで引いた QR コードを読み込む
2. スタート画面で「採掘をはじめる」をタップ
3. 画面を **タップしてツルハシを振り**、カードを削って鉱石を掘り出す
4. 掘り当てた鉱石の **運勢** と、シリアルNo.付きの **引換券** が表示される
5. 引換券をブースのスタッフに提示し、実物の宝石と交換する

## 出現する鉱石とおみくじ

| 鉱石 | レアリティ | 運勢 | 出現確率 |
| --- | --- | --- | --- |
| 石炭 | よくある | 末吉 | 34% |
| 鉄鉱石 | アンコモン | 小吉 | 26% |
| 金鉱石 | レア | 中吉 | 18% |
| ルビー | レア | 吉 | 10% |
| エメラルド | エピック | 大吉 | 8% |
| ダイヤモンド | ✦ レジェンダリー ✦ | 大当たり | 4% |

> [!NOTE]
> **こちらの鉱石ラインナップ・出現確率は在庫管理に応じて変更する予定。**

## 技術構成

- **単一ファイル (`index.html`)** で完結。HTML / CSS / バニラ JavaScript のみで、外部ライブラリやビルド工程は不要
- スマートフォンでの表示・タッチ操作に最適化（スクラッチ演出はキャンバスで実装）
- 結果は `localStorage` に保存され、**1 つの QR（`id`）につき 1 回だけ** 有効。引換券には交換防止用の「交換済」マークをスタッフが付けられる

## URL パラメータ

| パラメータ | 説明 |
| --- | --- |
| `id` | QR ごとに一意のキー。`1 QR = 1 結果` として管理される（例: `?id=booth-001`） |
| `ore` | 結果の鉱石を固定したい場合に指定（例: `?ore=diamond`）。指定しなければ上表の確率で抽選 |

## ローカルでの動作確認

`index.html` をブラウザで開くだけで動作します。スマホ実機で確認したい場合は、簡易サーバーを立てて同一ネットワークからアクセスしてください。

```bash
# 例: Python の簡易サーバー
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```
